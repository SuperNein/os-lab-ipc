# Управление процессами в ОС

**Лабораторная работа 2**

---

**Тема:** Обеспечение обмена данных между процессами посредством каналов

**Условие:** Родительский процесс создает два дочерних процесса. Взаимодействие между процессами осуществляется через каналы.

**Вариант:** Строки длины больше 10 символов отправляются в pipe2, иначе в pipe1. Дочерние процессы инвертируют строки.

---

## Сборка и запуск

### Требования

* Компилятор C++20
* CMake 3.16+

### 1. Конфигурация проекта

Создание папки сборки `build` и установка зависимостей:

```Bash
cmake -B build
```

### 2. Компиляция

```Bash
cmake --build build
```

### 3. Запуск

#### Основная программа

- **Linux / macOS:**

```Bash
./build/parent
```
    
- **Windows (PowerShell / cmd):**

```PowerShell
.\build\parent.exe
# Или для конфигурации Visual Studio:
.\build\Debug\parent.exe
```
